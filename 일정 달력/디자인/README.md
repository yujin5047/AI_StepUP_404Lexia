## 화면 1. 메인 화면

위에서 아래로:

1. **맨 위**: "일정 달력" 제목 + 별 모양 포인트 점수
2. **배경 색 고르기**: 동그라미를 누르면 배경 색이 바뀌어요.
   - 진한 색: 빨강 · 주황 · 노랑 · 초록 · 파랑 · 남색 · 보라 · 핑크 · 갈색
   - 연한 색: 같은 9가지의 연한 색
   - 연한 색을 고르면 제목 글씨가 진한 색으로 바뀌어요.
3. **달력**: 한 달 모양. 일정이 있는 날에는 점이 찍히고, 오늘은 테두리로 표시돼요. 날짜를 누르면 그날 일정이 아래에 나와요.
4. **그날 일정 목록**: 제목 / 시작~끝 시간 / `정규` 또는 `한 번` 표시. 네모를 누르면 완료 체크가 되고 +1.5점을 받아요.
5. **연속 보너스 안내**: 그날 일정을 전부 끝낸 날이 3일 연속 이어지면 +6점을 받아요.
6. **+ 일정 추가 버튼**

## 화면 2. 일정 추가 창 (일정 추가 버튼을 누르면 아래에서 올라와요)

1. **① 제목**: 일정 이름을 적어요. (예: 피아노 학원)
2. **② 시간**: 시작 시간과 끝 시간을 골라요.
3. **③ 어떤 일정이에요?**
   - **한 번**: 달력에서 지금 고른 날짜에만 생겨요.
   - **정규 (반복)**: 작은 달력이 나와서 반복할 날짜를 여러 개 골라요. 한 번 더 누르면 취소돼요.
4. **저장하기**: 창이 닫히고 달력과 일정 목록에 새 일정이 들어가요.

빠뜨린 게 있으면 알려 줘요.
- 제목이 없을 때: "제목을 써 주세요."
- 끝 시간이 시작 시간보다 빠를 때: "끝 시간은 시작 시간보다 늦어야 해요."
- 정규인데 날짜를 안 골랐을 때: "반복할 날짜를 하나 이상 골라 주세요."
