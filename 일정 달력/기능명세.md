# 일정 관리 앱 – 기능 명세

만든 사람: 404 Lexia
작성일: 2026-11-27

## 1. 일정 만들기 (순서대로)
1. **일정 추가** – '+ 일정 추가' 버튼을 누르면 새 일정 칸이 생긴다.
2. **일정 작성** – 일정 제목을 적는다. (예: 피아노 학원)
3. **시간 작성** – 시작 시간과 끝 시간을 둘 다 적는다. (예: 15:00 ~ 16:00)
4. **정규 / 비정규 구분**
   - 비정규: 한 번만 있는 일정
   - 정규: 반복되는 일정 → **달력에서 반복할 날짜를 선택**한다 (요일 X, 날짜 O)

## 2. 일정 끝낸 뒤
5. **완료 표시** – 끝낸 일정에 체크한다.
6. **포인트**
   - 모든 일정은 완료하면 포인트를 받는다.
   - **연속 보너스**: 그날 일정을 **전부** 끝낸 날이 며칠 연속 이어지면 보너스를 받는다.
   - 점수 (임시안, 바꿀 수 있음): 일정 1개 완료 = 1점 / 3일 연속 = +5점

## 정할 것
- 연속 보너스 점수와 기준 일수 확정
