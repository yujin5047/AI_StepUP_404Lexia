# 🍲 마라탕 타이쿤

재료를 고르고, 맵기를 정하고, 음료를 고르고, 계산한 다음 직접 먹어 보는 마라탕 가게 게임이에요.
휴대폰·패드에서 세로·가로 모두 플레이할 수 있고, 홈 화면에 앱처럼 설치할 수 있어요(PWA).

- 단계: ① 재료 → ② 맵기 → ③ 음료 → ④ 계산 → ⑤ 조리 → ⑥ 먹기 → 완뚝! (영수증)
- 재료(16+2가지, 무한으로 담기): 분모자, 뉴진면, 치즈떡, 넙적당면, 당면, 팽이버섯, 숙주, 배추, 청경채, 소세지, 비엔나, 유부, 판다분모자, 고구마떡, 옥수수, 소고기, 양고기, 떡
- 맵기: 0단계(순한맛) ~ 10단계(불지옥맛), 단계에 따라 국물 색이 바뀌어요
- 음료: 모구모구 2,000원 / 사이다·환타·콜라 1,500원 (먹다가 매울 때 마시기), 물은 무료
- 가격: 재료 100g에 2,000원 (10g = 200원), 맵기는 무료
- 계산대: 지폐(1,000~50,000원)와 동전(100·500원)으로 내고 거스름돈 받기
- 먹기: 젓가락으로 집어 먹기, 콤보, 매운 정도 게이지, 너무 매우면 불 뿜기 🔥

## 플레이하기
저장소 **Settings → Pages → Branch `main` / `(root)` → Save** 로 켜면 아래 주소에서 열려요.

https://yujin5047.github.io/AI_StepUP_404Lexia/마라탕%20타이쿤/

## 휴대폰에 설치하기
- 안드로이드(크롬): 간판 왼쪽의 [📲 앱 설치] 버튼, 또는 메뉴(⋮) → 홈 화면에 추가
- 아이폰(사파리): 공유 버튼 → 홈 화면에 추가
