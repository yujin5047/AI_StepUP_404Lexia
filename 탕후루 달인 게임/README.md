# 🍡 탕후루 달인

과일을 꽂고, 설탕을 묻히고, 식혀서 손님에게 파는 탕후루 만들기 게임이에요.
휴대폰·패드에서 가로 모드로 플레이하고, 홈 화면에 앱처럼 설치할 수 있어요(PWA).

- 단계: ① 과일 꽂기 → ② 설탕 묻히기 → ③ 식히기(팝핑캔디 토핑) → 결제(현금·카드·계좌이체)
- 과일: 딸기, 귤, 사과, 키위, 블랙사파이어, 거봉, 청포도, 레몬
- 가격: 3,000원 (별이 하나 깎일 때마다 500원 할인)
- 팝핑캔디를 원하는 손님 / 안 먹는 손님이 있어요

## 플레이하기
저장소 **Settings → Pages → Branch `main` / `(root)` → Save** 로 켜면 아래 주소에서 열려요.

https://yujin5047.github.io/AI_StepUP_404Lexia/탕후루%20달인%20게임/

## 휴대폰에 설치하기
- 안드로이드(크롬): 시작 화면의 [📲 앱 설치] 버튼, 또는 메뉴(⋮) → 홈 화면에 추가
- 아이폰(사파리): 공유 버튼 → 홈 화면에 추가

## 파일
| 파일 | 설명 |
|---|---|
| index.html | 게임 본체 |
| manifest.webmanifest | 앱 이름·아이콘·가로 모드 설정 |
| sw.js | 한 번 열면 인터넷 없이도 실행 |
| icon-*.png, apple-touch-icon.png | 앱 아이콘 |
