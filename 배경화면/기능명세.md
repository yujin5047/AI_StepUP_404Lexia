# 배경화면 앱 – 기능 명세 (기획 확인용)

만든 사람: 404 Lexia
작성일: 2026-11-28
상태: **기획 확인 중** (확인이 끝나면 만들기 시작)

## 한 줄 소개
사진을 검색해서 다운로드하고, 마음에 드는 사진이나 색으로 배경화면을 바꾸는 앱

## 화면 구성
- **탭 1. 색 배경화면** – 앱이 직접 만든 색 배경화면
- **탭 2. 사진 찾기** – 검색해서 사진 고르기
- **탭 3. 내 배경화면** – 지금 쓰는 배경화면, 찜한 것 모아 보기

## 1. 색 배경화면 (앱이 직접 만든 것)
1. **색 고르기** – 색 10개 중에서 하나를 누른다.
2. **진하게 / 연하게** – 버튼으로 진한 색 / 연한 색을 바꾼다.
3. **미리보기** – 고른 색이 화면에 크게 보인다.
4. **적용 / 저장** – '배경으로 쓰기' 또는 '다운로드'를 누른다.

→ 모두 **20가지** 색 배경화면

## 2. 사진 찾기 (순서대로)
1. **검색** – 검색창에 단어를 적는다. (예: 바다, 우주, 고양이)
   - 자주 쓰는 검색어 버튼도 있다: 자연 / 동물 / 우주 / 바다 / 꽃
2. **사진 목록** – 찾은 사진이 바둑판처럼 보인다.
3. **크게 보기** – 사진을 누르면 크게 보인다. 아래에 **사진 찍은 사람 이름**이 나온다.
4. **다운로드** – '다운로드' 버튼을 누르면 사진이 내 기기에 저장된다.
5. **배경으로 쓰기** – 누르면 앱 배경이 이 사진으로 바뀐다.
6. **찜하기 ♥** – 마음에 드는 사진을 '내 배경화면'에 모아 둔다.

- 사진 출처: **Pexels** (무료, 1시간에 200번까지 검색 가능)
- API 키는 보호자/멘토가 가입해서 받는다.

## 3. 배경화면 바꾸기
- 앱 안의 배경이 고른 색이나 사진으로 바뀐다.
- 앱을 껐다 켜도 마지막 배경화면이 그대로 남아 있다.
- **휴대폰/컴퓨터 바탕화면**은 웹앱이 직접 바꿀 수 없다.
  → '다운로드'로 저장한 뒤, 기기 설정에서 직접 바탕화면으로 지정한다.
